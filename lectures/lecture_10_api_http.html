1. What is an API?

An API (Application Programming Interface) is a way for your app to get data from a server on the internet. You send a request, the server sends back a response — usually in JSON format.

Flutter App             Internet             DummyJSON Server
        ── GET /products ──────────────────────────→
        ←── JSON response ──────────────────────────

We use DummyJSON (dummyjson.com) — a free fake product API. No account or API key needed.

EndpointWhat it returns
dummyjson.com/products?limit=20List of 20 products
dummyjson.com/products/search?q=phoneProducts matching "phone"

2. What is JSON?

JSON (JavaScript Object Notation) is the standard format for sending data over the internet. It looks like a Dart Map. 

// JSON response from dummyjson.com/products
{
  "products": [
    {
      "id": 1,
      "title": "Essence Mascara Lash Princess",
      "price": 9.99,
      "category": "beauty",
      "thumbnail": "https://cdn.dummyjson.com/...",
      "rating": 4.7
    },
    ...
  ]
}

In Dart, we use jsonDecode() to convert this JSON string into a Map<String, dynamic> that we can read like a normal Dart map.

4. Adding the http Package

pubspec.yaml

dependencies:
  http: ^1.2.0    ← add this

Run flutter pub get in the terminal.

AndroidManifest.xml — internet permission required on Android:

<manifest>
  <uses-permission android:name="android.permission.INTERNET"/>  ← add this
  <application ...>
Without the internet permission, network requests will silently fail on Android even though the code is correct. Always add this line before testing.

5. Product Model Class

We create a Product class to represent one product. The factory constructor fromJson() converts a raw JSON map into a clean Dart object.

lib/models/product.dart 
class Product {
  final int id;
  final String title;
  final double price;
  final String description;
  final String category;
  final String thumbnail;  // image URL
  final double rating;

  Product({
    required this.id,    required this.title,
    required this.price, required this.description,
    required this.category, required this.thumbnail,
    required this.rating,
  });

  // Converts a JSON map → Product object
  factory Product.fromJson(Map<String, dynamic> json) {
    return Product(
      id:          json['id'],
      title:       json['title'],
      price:       (json['price'] as num).toDouble(),
      description: json['description'],
      category:    json['category'],
      thumbnail:   json['thumbnail'],
      rating:      (json['rating'] as num).toDouble(),
    );
  }
}
Why cast to num first? JSON numbers can be integers (9) or decimals (9.99). Casting to num first, then calling .toDouble(), handles both cases safely.

6. ProductService — API Calls

lib/services/product_service.dart 
import 'dart:convert';
import 'package:http/http.dart' as http;
import 'package:flutter_application_2/models/product.dart';

class ProductService {
  static const String _baseUrl = 'https://dummyjson.com';

  static Future<List<Product>> getProducts() async {
    // 1. Make the HTTP GET request
    final response = await http.get(
      Uri.parse('$_baseUrl/products?limit=20'),
    );

    // 2. Check the status code — 200 means success
    if (response.statusCode == 200) {
      final data = jsonDecode(response.body);      // JSON string → Map
      final List productsJson = data['products']; // get the array
      // 3. Convert each JSON map into a Product object
      return productsJson.map((p) => Product.fromJson(p)).toList();
    }

    throw Exception('Failed to load products');
  }

  static Future<List<Product>> searchProducts(String query) async {
    final response = await http.get(
      Uri.parse('$_baseUrl/products/search?q=$query'),
    );
    if (response.statusCode == 200) {
      final data = jsonDecode(response.body);
      return (data['products'] as List)
          .map((p) => Product.fromJson(p))
          .toList();
    }
    throw Exception('Failed to search products');
  }
}

CodeMeaning

404Not Found — wrong URL
500Server Error — something wrong on the server

7. FutureBuilder — The Key Widget

A network request takes time. FutureBuilder is a widget that watches a Future and automatically rebuilds when its state changes. It handles three states so you don't have to.

FutureBuilder watches _productsFuture

  ConnectionState.waiting  → show CircularProgressIndicator
  snapshot.hasError        → show error message
  snapshot.hasData         → show ListView with products 
FutureBuilder<List<Product>>(
  future: _productsFuture,   // the async operation to watch
  builder: (context, snapshot) {

    // Still loading
    if (snapshot.connectionState == ConnectionState.waiting) {
      return const Center(child: CircularProgressIndicator());
    }

    // Error occurred
    if (snapshot.hasError) {
      return Center(child: Text('Error: ${snapshot.error}'));
    }

    // Data ready — snapshot.data! is List<Product>
    final products = snapshot.data!;
    return ListView.builder(
      itemCount: products.length,
      itemBuilder: (context, index) {
        return Text(products[index].title);
      },
    );
  },
)
Important: Store the Future in a variable (late Future _productsFuture) and assign it in initState(). If you call ProductService.getProducts() directly inside build(), it will make a new network request every time the widget rebuilds — causing infinite loading loops. 
// ✅ Correct — Future created once in initState
late Future<List<Product>> _productsFuture;

@override
void initState() {
  super.initState();
  _productsFuture = ProductService.getProducts(); // called once
}

// ❌ Wrong — new request on every rebuild
FutureBuilder(
  future: ProductService.getProducts(), // called every rebuild!
  ...
)

8. Displaying Network Images

Product thumbnails are URLs, not local assets. We use Image.network() to load them from the internet. 

Image.network(
  product.thumbnail,   // the URL string from the API
  width: 90,
  height: 90,
  fit: BoxFit.cover,
  // Show a placeholder while the image is downloading
  loadingBuilder: (context, child, progress) {
    if (progress == null) return child; // image fully loaded
    return Container(
      width: 90, height: 90,
      color: Colors.grey[200],
      child: const Center(child: CircularProgressIndicator(strokeWidth: 2)),
    );
  },
)
WidgetSourceUse when
Image.asset()Local file in assets/Logo, icons — shipped with the app
Image.network()URL from the internetProduct images, user avatars from API
