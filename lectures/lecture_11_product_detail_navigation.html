Lecture 11  –  Product Detail Screen & Navigation

Topics: Passing data between screens  ·  Navigator.push  ·  InkWell  ·  Detail screen layout  ·  Back navigation

Learning Objectives

  2. Pass a data object from one screen to another via a constructor parameter.

Back buttonNo — tabs are siblingsYes — automatically shown in AppBar

2. Passing Data to Another Screen

When navigating to a detail screen, we need to send the selected product along. The simplest way is to pass it through the screen's constructor. 

// ProductDetailScreen declares a required constructor parameter
class ProductDetailScreen extends StatelessWidget {
  final Product product; // ← receives the product from the caller

  const ProductDetailScreen({super.key, required this.product});
  ...
}

// Caller passes the product when navigating
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (_) => ProductDetailScreen(product: product), // ← pass it here
  ),
);
No API call needed on the detail screen. The product object is already in memory — we just pass it along. The detail screen reads from it directly.

3. InkWell — Making Any Widget Tappable

InkWell is a widget that wraps any child and makes it respond to taps. It shows a ripple (ink splash) effect when tapped — the standard Material Design touch feedback. 

// Wrapping a Card with InkWell to make it tappable
Card(
  child: InkWell(
    borderRadius: BorderRadius.circular(12), // ripple follows card shape
    onTap: () {
      Navigator.push(
        context,
        MaterialPageRoute(
          builder: (_) => ProductDetailScreen(product: product),
        ),
      );
    },
    child: Padding( ... ), // the card content
  ),
)

InkWell vs GestureDetector

InkWellGestureDetector
Ripple effectYes ✓No
Material feelYes ✓No
Use whenInside Material widgets (Card, Container)Custom gestures (swipe, long press, drag)
ListTile already has onTap built in — no need to wrap it with InkWell. Just set ListTile(onTap: () { ... }) directly.

class ProductDetailScreen extends StatelessWidget {
  final Product product;
  const ProductDetailScreen({super.key, required this.product});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // AppBar shows back button automatically — no code needed
      appBar: AppBar(
        title: Text(product.title, maxLines: 1, overflow: TextOverflow.ellipsis),
        backgroundColor: Colors.orangeAccent,
        foregroundColor: Colors.white,
      ),

      body: SingleChildScrollView(
        child: Column(
          children: [
            // 1. Full-width image
            SizedBox(
              width: double.infinity, height: 280,
              child: Image.network(product.thumbnail, fit: BoxFit.cover),
            ),

            Padding(
              padding: const EdgeInsets.all(16),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  // 2. Category badge
                  Container(
                    padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 4),
                    decoration: BoxDecoration(
                      color: Colors.orangeAccent.withValues(alpha: 0.15),
                      borderRadius: BorderRadius.circular(20),
                    ),
                    child: Text(product.category.toUpperCase()),
                  ),
                  // 3. Title
                  Text(product.title, style: TextStyle(fontSize: 22, fontWeight: FontWeight.bold)),
                  // 4. Price + Rating row
                  Row(
                    mainAxisAlignment: MainAxisAlignment.spaceBetween,
                    children: [
                      Text('\$${product.price}'),
                      Text('⭐ ${product.rating}'),
                    ],
                  ),
                  // 5. Description
                  Text(product.description),
                  // 6. Add to Cart button
                  ElevatedButton.icon(
                    icon: const Icon(Icons.shopping_cart_outlined),
                    label: const Text('Add to Cart'),
                    onPressed: () { ... },
                  ),
                ],
              ),
            ),
          ],
        ),
      ),
    );
  }
}

5. How the Back Button Works Automatically

When you use Navigator.push, Flutter adds the new screen to a navigation stack. The AppBar automatically shows a back arrow (←) at the top left. Tapping it calls Navigator.pop(context) which removes the top screen and returns to the previous one.

Before tap:   [ HomeTab ]                   ← stack has 1 screen

After tap:    [ HomeTab | ProductDetailScreen ]  ← stack has 2 screens
                                               ↑ user sees this one

After back:  [ HomeTab ]                   ← pop removed the detail screen 
// You can also call pop manually from a button
ElevatedButton(
  onPressed: () => Navigator.pop(context), // same as the back button
  child: const Text('Go Back'),
)

7. withValues(alpha:) — Replacing Deprecated withOpacity()

When creating a semi-transparent color for the category badge, the old withOpacity() method is now deprecated in Flutter. Use withValues(alpha:) instead — it works the same way but with better precision. 

// ❌ Old — deprecated
color: Colors.orangeAccent.withOpacity(0.15)

// ✅ New — use this
color: Colors.orangeAccent.withValues(alpha: 0.15)

9. Practice Tasks

  1. Add a share icon in the detail screen's AppBar actions using Icons.share — show a SnackBar when tapped.
  2. Show the product id as a small grey text below the title (e.g. "Product #1").
  3. Add a favourite button (Icons.favorite_border) on the product card. When tapped, toggle it to Icons.favorite in red — without opening the detail screen (hint: use GestureDetector on just the icon, not the whole card).
  4. Challenge: When the "Add to Cart" button is tapped on the detail screen, navigate back to the Cart tab. Hint: Navigator.pop returns to the previous screen, but to switch tabs you need to pass a callback or use a shared state.
