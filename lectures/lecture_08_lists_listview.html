1. Dart List — Quick Recap

A List in Dart is an ordered collection of items. You can add, remove, and loop through items. 

// Create a list of strings
List<String> fruits = ['Apple', 'Banana', 'Mango'];

// Access by index (starts at 0)
fruits[0]; // 'Apple'

// Add an item
fruits.add('Orange');

// Remove by index
fruits.removeAt(1); // removes 'Banana'

// Number of items
fruits.length; // 3

// Loop through items
for (final fruit in fruits) {
  print(fruit);
}
Type safety: List<String> means the list can only hold strings. List<CartItem> means it can only hold CartItem objects. This prevents bugs at compile time.

2. ListView vs ListView.builder

ListViewListView.builder
How items are definedListed manually inside children: []Built one at a time by a function
Best forSmall, fixed lists (3–10 items)Any size list, especially dynamic ones
PerformanceBuilds all items at onceBuilds only visible items (lazy)
List data needed?No — items written in code directlyYes — reads from a Dart List

ListView — fixed items written manually

ListView(
  children: [
    ListTile(title: Text('Flutter')),
    ListTile(title: Text('Dart')),
    ListTile(title: Text('Android')),
  ],
)

ListView.builder — built from a Dart list

ListView.builder(
  itemCount: fruits.length,           // how many items
  itemBuilder: (context, index) {     // called once per item
    return ListTile(
      title: Text(fruits[index]),      // use index to get the item
    );
  },
)
Rule of thumb: If the number of items can change at runtime (add/remove), always use ListView.builder. It works with setState seamlessly.

3. Data Model Class

Instead of storing data in separate lists (one for names, one for prices), we group related data into a model class. This makes the code cleaner and easier to read. 

// ❌ Without a model — messy, easy to get indices wrong
List<String> names  = ['Flutter Book', 'Mouse'];
List<double> prices = [1200, 850];

// ✅ With a model — clean, data grouped together
class CartItem {
  final String name;
  final double price;

  CartItem({required this.name, required this.price});
}

List<CartItem> items = [
  CartItem(name: 'Flutter Book', price: 1200),
  CartItem(name: 'Mouse',        price: 850),
];

5. SearchScreen — Basic ListView

The Search screen shows a fixed list of technology topics using a plain ListView. Each item is built by mapping the string list to a Card + ListTile.

lib/screens/search_screen.dart 
class SearchScreen extends StatelessWidget {
  const SearchScreen({super.key});

  static const List<String> _items = [
    'Flutter', 'Dart', 'Android', 'iOS',
    'React Native', 'Kotlin', 'Swift', 'Firebase',
  ];

  @override
  Widget build(BuildContext context) {
    return ListView(
      padding: const EdgeInsets.all(12),
      // .map() converts each string to a Card widget
      // .toList() converts the result back to a List<Widget>
      children: _items.map((item) {
        return Card(
          child: ListTile(
            leading: const Icon(Icons.search, color: Colors.orangeAccent),
            title: Text(item),
          ),
        );
      }).toList(),
    );
  }
}

6. CartScreen — Dynamic ListView.builder

The Cart screen is more advanced. The list changes at runtime — items can be added and removed. We use ListView.builder and setState to keep the UI in sync with the data.

lib/screens/cart_screen.dart 
class CartItem {
  final String name;
  final double price;
  CartItem({required this.name, required this.price});
}

class _CartScreenState extends State<CartScreen> {

  // The live list — changes here trigger a UI rebuild
  final List<CartItem> _cartItems = [
    CartItem(name: 'Flutter Book', price: 1200),
    CartItem(name: 'Wireless Mouse', price: 850),
  ];

  // Add an item — setState tells Flutter to rebuild the ListView
  void _addItem() {
    setState(() {
      _cartItems.add(CartItem(name: 'New Item', price: 500));
    });
  }

  // Remove an item by its index
  void _removeItem(int index) {
    setState(() {
      _cartItems.removeAt(index);
    });
  }

  // Calculated total — runs every time build() runs
  double get _total => _cartItems.fold(0, (sum, item) => sum + item.price);

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        Expanded(
          child: ListView.builder(
            itemCount: _cartItems.length,       // how many rows
            itemBuilder: (context, index) {     // builds one row at a time
              final item = _cartItems[index];
              return Card(
                child: ListTile(
                  leading: CircleAvatar(child: Text('${index + 1}')),
                  title: Text(item.name),
                  subtitle: Text('Rs. ${item.price}'),
                  trailing: IconButton(
                    icon: const Icon(Icons.delete_outline, color: Colors.red),
                    onPressed: () => _removeItem(index),
                  ),
                ),
              );
            },
          ),
        ),
        // Total + Add button at the bottom
        Container(
          padding: const EdgeInsets.all(16),
          child: Row(
            mainAxisAlignment: MainAxisAlignment.spaceBetween,
            children: [
              Text('Total: Rs. ${_total}',
                style: const TextStyle(fontWeight: FontWeight.bold)),
              ElevatedButton.icon(
                icon: const Icon(Icons.add),
                label: const Text('Add Item'),
                onPressed: _addItem,
              ),
            ],
          ),
        ),
      ],
    );
  }
}

7. How ListView.builder Works Internally

_cartItems = [ CartItem('Book', 1200), CartItem('Mouse', 850), CartItem('Cable', 350) ]

ListView.builder called with itemCount: 3

  itemBuilder(context, 0) → builds Card for 'Book'
  itemBuilder(context, 1) → builds Card for 'Mouse'
  itemBuilder(context, 2) → builds Card for 'Cable'

User taps delete on index 1 → _cartItems.removeAt(1) → setState()

  itemBuilder(context, 0) → builds Card for 'Book' ✓
  itemBuilder(context, 1) → builds Card for 'Cable' ✓ ← index shifted up
Why Expanded? ListView tries to take infinite height. Inside a Column, this causes an error. Wrapping it in Expanded tells it: "take all remaining space in the Column" — problem solved.

8. The fold() Method — Calculating a Total

fold() is a Dart List method that reduces a list to a single value by running a function on each item. 

// fold(startingValue, function)
// 'sum' starts at 0, then adds each item's price one by one
double total = _cartItems.fold(0, (sum, item) => sum + item.price);

// Equivalent to writing:
double total = 0;
for (final item in _cartItems) {
  total += item.price;
}
