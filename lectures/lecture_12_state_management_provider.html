1. The Problem — Why setState Is Not Enough

In previous lectures, we used setState() to update the UI. That works great when the data only belongs to one screen. But what happens when two screens need to share the same data?

Think about our shopping app:

  • The user taps "Add to Cart" on the Product Detail screen
  • They go back and tap the Cart tab
  • The cart should show the product they just added

With setState, each screen has its own separate data. There is no way for the Product Detail screen to tell the Cart screen: "hey, I added something!"

❌ Problem with setState

  • Cart data lives inside CartScreen only
  • ProductDetailScreen cannot access it
  • Adding a product does nothing visible in Cart
  • Data is lost when screen rebuilds

✅ Solution with Provider

  • Cart data lives in ONE central place
  • Any screen can read or modify it
  • All screens update automatically
  • Data persists as long as the app runs

2. What Is State Management?

State = data that can change and that the UI needs to display.
State management = a way to store that data in one place and share it across the app.

Imagine a whiteboard in the classroom:

  • Anyone can read what is written on it
  • Anyone can erase and write new things
  • Everyone in the room sees the update immediately

CartProvider is our whiteboard. All screens look at it. When one screen changes it, everyone else updates.

main.dart
└── ChangeNotifierProvider (CartProvider) ← the whiteboard
    ├── HomeScreen
    ├── ProductDetailScreen  ← writes to whiteboard (addProduct)
    ├── CartScreen            ← reads from whiteboard (items, total)
    └── ProfileScreen

4. Step 1 — Create the CartProvider

Create a new file: lib/providers/cart_provider.dart

This class holds all cart data and the logic to change it.

lib/providers/cart_provider.dart 
import 'package:flutter/material.dart';
import 'package:flutter_application_2/models/product.dart';

// CartItem holds one product + how many the user wants
class CartItem {
  final Product product;
  int quantity;

  CartItem({required this.product, this.quantity = 1});
}

// CartProvider is the "brain" of the cart.
// It extends ChangeNotifier — this gives it the ability to
// notify (inform) widgets whenever something changes.
class CartProvider extends ChangeNotifier {

  // Private list — only this class can modify it
  final List<CartItem> _items = [];

  // Public getter — widgets can read but not change the list
  List<CartItem> get items => List.unmodifiable(_items);

  // Total number of products (for the cart badge)
  int get totalItems => _items.fold(0, (sum, item) => sum + item.quantity);

  // Total price
  double get totalPrice =>
      _items.fold(0, (sum, item) => sum + item.product.price * item.quantity);

  // Add a product. If it is already in the cart, increase quantity.
  void addProduct(Product product) {
    final index = _items.indexWhere((item) => item.product.id == product.id);

    if (index >= 0) {
      _items[index].quantity++;   // already in cart → increase quantity
    } else {
      _items.add(CartItem(product: product));  // new → add it
    }

    notifyListeners();  // 🔔 tell all widgets to rebuild
  }

  // Remove a product completely
  void removeProduct(int productId) {
    _items.removeWhere((item) => item.product.id == productId);
    notifyListeners();
  }

  // Decrease quantity by 1, remove if it reaches 0
  void decreaseQuantity(int productId) {
    final index = _items.indexWhere((item) => item.product.id == productId);
    if (index >= 0) {
      if (_items[index].quantity > 1) {
        _items[index].quantity--;
      } else {
        _items.removeAt(index);
      }
      notifyListeners();
    }
  }

  // Clear all items
  void clearCart() {
    _items.clear();
    notifyListeners();
  }
}
Key Concept: notifyListeners() is the most important line. It is like sending a broadcast: "Hey everyone, the cart changed! Please update your UI." Any widget that is listening will automatically rebuild.

5. Step 2 — Provide CartProvider to the Whole App

For any screen to access CartProvider, we must place it above MaterialApp in main.dart. Think of it like placing the whiteboard at the entrance of the building — everyone inside can see it.

lib/main.dart 
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';
import 'package:flutter_application_2/providers/cart_provider.dart';
import 'package:flutter_application_2/screens/splash.dart';

void main() {
  runApp(
    // ChangeNotifierProvider creates ONE CartProvider and makes it
    // available to every widget in the app below it.
    ChangeNotifierProvider(
      create: (context) => CartProvider(),
      child: MaterialApp(
        title: 'My App',
        debugShowCheckedModeBanner: false,
        home: SplashScreen(),
      ),
    ),
  );
}
Common Mistake: If you place ChangeNotifierProvider inside a screen instead of above MaterialApp, other screens won't be able to access it and you will get an error: "Could not find the correct Provider".

6. Step 3 — Reading State With Consumer

There are two ways to access a Provider from a widget:

Method When to Use Rebuilds Widget?
Consumer<CartProvider> When you need to display data from the provider Yes — rebuilds whenever notifyListeners() is called
context.read<CartProvider>() When you just want to call a method (like addProduct) No — just calls the method, doesn't listen

Using Consumer in cart_screen.dart

lib/screens/cart_screen.dart 
import 'package:provider/provider.dart';
import 'package:flutter_application_2/providers/cart_provider.dart';

class CartScreen extends StatelessWidget {  // no longer StatefulWidget!
  const CartScreen({super.key});

  @override
  Widget build(BuildContext context) {
    // Consumer listens to CartProvider.
    // The 'cart' variable is the CartProvider instance.
    return Consumer<CartProvider>(
      builder: (context, cart, child) {
        return Column(
          children: [
            Expanded(
              child: cart.items.isEmpty
                  ? const Center(child: Text('Your cart is empty'))
                  : ListView.builder(
                      itemCount: cart.items.length,
                      itemBuilder: (context, index) {
                        final cartItem = cart.items[index];
                        return Card(
                          child: ListTile(
                            title: Text(cartItem.product.title),
                            subtitle: Text('\$${cartItem.product.price}'),
                            trailing: Row(
                              mainAxisSize: MainAxisSize.min,
                              children: [
                                IconButton(
                                  icon: const Icon(Icons.remove_circle_outline),
                                  onPressed: () {
                                    // context.read() for one-time actions
                                    context.read<CartProvider>()
                                        .decreaseQuantity(cartItem.product.id);
                                  },
                                ),
                                Text('${cartItem.quantity}'),
                                IconButton(
                                  icon: const Icon(Icons.add_circle_outline),
                                  onPressed: () {
                                    context.read<CartProvider>()
                                        .addProduct(cartItem.product);
                                  },
                                ),
                                IconButton(
                                  icon: const Icon(Icons.delete_outline,
                                      color: Colors.red),
                                  onPressed: () {
                                    context.read<CartProvider>()
                                        .removeProduct(cartItem.product.id);
                                  },
                                ),
                              ],
                            ),
                          ),
                        );
                      },
                    ),
            ),

            // Show total and checkout button only if cart has items
            if (cart.items.isNotEmpty)
              Container(
                padding: const EdgeInsets.all(16),
                child: Row(
                  mainAxisAlignment: MainAxisAlignment.spaceBetween,
                  children: [
                    Text('Total: \$${cart.totalPrice.toStringAsFixed(2)}',
                        style: const TextStyle(fontWeight: FontWeight.bold)),
                    ElevatedButton(
                      onPressed: () => context.read<CartProvider>().clearCart(),
                      child: const Text('Checkout'),
                    ),
                  ],
                ),
              ),
          ],
        );
      },
    );
  }
}

7. Step 4 — Writing State From ProductDetailScreen

Now we connect the "Add to Cart" button. When it is tapped, we call context.read<CartProvider>().addProduct(product). This updates the cart, and notifyListeners() makes the Cart screen update automatically.

lib/screens/product_detail_screen.dart 
import 'package:provider/provider.dart';
import 'package:flutter_application_2/providers/cart_provider.dart';

// Inside the build method, in the Add to Cart button:

Consumer<CartProvider>(
  builder: (context, cart, child) {
    // Check if this product is already in the cart
    final alreadyInCart =
        cart.items.any((item) => item.product.id == product.id);

    return ElevatedButton.icon(
      style: ElevatedButton.styleFrom(
        // Button turns green if product is already in cart
        backgroundColor: alreadyInCart ? Colors.green : Colors.orangeAccent,
        foregroundColor: Colors.white,
      ),
      icon: Icon(alreadyInCart ? Icons.check : Icons.shopping_cart_outlined),
      label: Text(alreadyInCart ? 'Added to Cart' : 'Add to Cart'),
      onPressed: () {
        // This is all it takes — Provider does the rest
        context.read<CartProvider>().addProduct(product);
      },
    );
  },
),
Result: When the user taps "Add to Cart", the button instantly turns green and shows "Added to Cart". When the user navigates to the Cart tab, the product is already there — no extra code needed.

8. How It All Connects — The Full Flow

User taps "Add to Cart" on ProductDetailScreen
↓
context.read<CartProvider>().addProduct(product)
↓
CartProvider adds item to _items list
↓
notifyListeners() is called
↓
All Consumer<CartProvider> widgets rebuild
↓
CartScreen shows the new item ✅    Button turns green ✅

9. Quick Reference — Provider Cheat Sheet

What You Want to Do Code
Create the provider (once, in main.dart) ChangeNotifierProvider(create: (_) => CartProvider(), child: ...)
Display data and auto-rebuild Consumer<CartProvider>(builder: (ctx, cart, _) { ... })
Call a method (one-time action) context.read<CartProvider>().addProduct(p)
Read a value (rebuilds widget) context.watch<CartProvider>().totalItems
Notify listeners after change notifyListeners() inside CartProvider
Rule of Thumb: Use Consumer or context.watch() when you want the widget to rebuild. Use context.read() inside onPressed or other callbacks when you just want to call a method.
